### III. RINGKASAN / URAIAN SINGKAT CIPTAAN (UNTUK FORMULIR E-HAKCIPTA DJKI)

> **Uraian Singkat Ciptaan (Maksimal 300 kata untuk portal e-Hakcipta):**
> 
> "Ciptaan ini merupakan karya Program Komputer berupa perangkat lunak permainan edukasi interaktif berbasis web bernama *Puzzle Puzzle: Game Kampus Ceria*. Program dirancang khusus untuk mendukung masa orientasi, pengenalan lingkungan kampus, dan pembelajaran visual spasial bagi mahasiswa dan civitas akademika dengan mengusung estetika *modern green-campus*. 
>
> Keunggulan inovasi program komputer ini meliputi:
> 1. Algoritma komputasi pengacakan matriks ubin (tile shuffling) adaptif dengan tingkat kesulitan multi-dimensi (3x3, 4x4, hingga 5x5);
> 2. Pemanfaatan *HTML5 Canvas Vector Processing* yang mampu membelah citra SVG resolusi tinggi dan citra raster secara presisi tanpa degradasi visual;
> 3. Integrasi mesin suara prosedural mandiri (*Synthesizer Web Audio API*) yang menghasilkan efek audio interaktif dinamis tanpa ketergantungan pada file audio eksternal;
> 4. Sistem kompetisi real-time berbasis papan peringkat (*Leaderboard Storage*) yang mencatat efisiensi waktu penyelesaian dan jumlah langkah pergerakan ubin;
> 5. Arsitektur *responsive single-page application* (SPA) modern yang dibangun menggunakan TypeScript, React, Tailwind CSS, dan Vite, sehingga dapat diakses secara instan lintas peramban pada perangkat desktop maupun seluler tanpa instalasi tambahan."

---

### IV. SPESIFIKASI TEKNIS PROGRAM KOMPUTER
- **Bahasa Pemrograman** : TypeScript, JavaScript (ECMAScript 2022+), HTML5, CSS3
- **Framework & Runtime** : React 18+, Vite 6+, Tailwind CSS v4
- **Arsitektur Pemrosesan Citra** : Canvas 2D Context, Dynamic Slice Matrix Math
- **Arsitektur Audio** : Web Audio API (OscillatorNode, GainNode, BiquadFilterNode)
- **Kompatibilitas Sistem Operasi** : Platform Independent (Windows, macOS, Linux, Android, iOS via Web Browser Modern)
- **Peramban Didukung** : Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, Opera

### V. MANFAAT DAN KEBARUAN (NOVELTY) ILMIAH
1. **Efektivitas Pedagogis**: Menggabungkan latihan kognitif konsentrasi dan persepsi spasial mahasiswa baru dengan pengenalan simbol-simbol institusional kampus secara menyenangkan (*joyful learning*).

3. **Akuntabilitas Capaian Permainan**: Adanya metrik ganda (waktu tempuh presisi milidetik dan efisiensi langkah gerak) memberikan dasar evaluasi ketelitian motorik halus pengguna.
