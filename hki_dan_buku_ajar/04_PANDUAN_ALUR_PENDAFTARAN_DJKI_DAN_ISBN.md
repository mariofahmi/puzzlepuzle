## BAGIAN I: ALUR PENDAFTARAN HAK CIPTA PROGRAM KOMPUTER (DJKI KEMENKUMHAM)

Karya software/game web Anda (*Puzzle Puzzle, TTS VCT, Peradilan Semu, dsb.*) dilindungi oleh **UU No. 28 Tahun 2014 tentang Hak Cipta** kategori **Program Komputer** (Masa perlindungan: **50 tahun**).

### A. Dokumen Persyaratan yang Harus Diunggah:
1. **Surat Pernyataan Hak Cipta** (Bermeterai Rp10.000,- ditandatangani pencipta).
2. **Surat Pengalihan Hak Cipta** *(Khusus jika pemegang hak dialihkan ke Kampus UNIROW Tuban)*.
3. **Scan KTP Pencipta** (Format PDF/JPG).
4. **Contoh Ciptaan (Wajib)**:
   - File Dokumen PDF berisi gabungan:
     - Halaman Judul & Uraian Ciptaan (dari file `01_URAIAN_CIPTAAN_HKI_DJKI.md`)
     - Manual Book / Petunjuk Penggunaan (dari file `02_MANUAL_BOOK_PANDUAN_PENGGUNAAN.md`)
     - Tangkapan layar antarmuka aplikasi (*Screenshot*)
     - Potongan kode program (*Source Code Sample*, misal 10–20 halaman pertama file `.tsx`/`.ts`).

### B. Prosedur Pendaftaran:
1. **Opsi 1: Melalui Sentra HKI LPPM UNIROW Tuban (Disarankan)**:
   - Serahkan berkas yang telah kita siapkan di folder `hki_dan_buku_ajar/` ke pengelola Sentra HKI LPPM UNIROW.
   - Pendaftaran melalui Sentra HKI kampus sering kali memperoleh fasilitas subsidi biaya PNBP perguruan tinggi.
2. **Opsi 2: Mandiri melalui Portal Resmi DJKI**:
   - Buka portal [https://e-hakcipta.dgip.go.id/](https://e-hakcipta.dgip.go.id/).
   - Buat akun pemohon atau masuk ke akun terdaftar.
   - Pilih menu **Permohonan Baru** -> Jenis Ciptaan: **Program Komputer**.
   - Masukkan judul ciptaan, tanggal pertama kali diumumkan, dan uraian singkat yang telah disiapkan.
   - Unggah seluruh berkas lampiran.
   - Lakukan pembayaran billing PNBP (Rp200.000,- untuk UMKM/Lembaga Pendidikan atau Rp400.000,- untuk Umum).
   - Surat Pencatatan Ciptaan (Sertifikat HKI resmi ber-QR Code dari Menteri Hukum dan HAM) biasanya terbit secara otomatis dalam 1–3 hari kerja.

## BAGIAN II: ALUR PENERBITAN BUKU AJAR BER-ISBN RESMI PERPUSNAS

Menerbitkan buku ajar ber-ISBN berbasis kumpulan media gamifikasi edukasi Anda akan memberikan dampak sitasi ilmiah dan poin kumulatif yang sangat besar bagi karir akademik dosen.

### A. Rincian Angka Kredit Dosen (KUM PAK / BKD):
| Jenis Karya | Poin Angka Kredit (KUM) | Keterangan |
|---|---|---|
| **Buku Ajar Ber-ISBN** | **20 KUM** | Diterbitkan penerbit resmi anggota IKAPI, format standar UNESCO ($15.5 \times 23$ cm), minimal 49 halaman, selaras dengan RPS mata kuliah. |
| **Hak Cipta Program Komputer (Sertifikat DJKI)** | **10 – 15 KUM** | Sertifikat resmi dari Kemenkumham RI atas nama pencipta. |
| **Total Potensi Akumulasi** | **30 – 35 KUM** | Sangat signifikan untuk percepatan kenaikan jabatan fungsional (Lektor ke Lektor Kepala / Guru Besar). |

### B. Langkah Eksekusi Penerbitan Buku Ajar:
1. **Penyusunan Naskah Lengkap**:
   - Gunakan outline pada file `03_BLUEPRINT_BUKU_AJAR_BER_ISBN.md`.
   - Per bab dilengkapi: Capaian Pembelajaran, Uraian Materi, Studi Kasus Nyata (Puzzle, TTS, Simulasi), Rangkuman, dan Latihan Tugas Mahasiswa.
2. **Gandeng Penerbit Anggota Resmi IKAPI**:
   - Kerjasama dengan Penerbit Kampus (UNIROW Press) atau Penerbit Pendidikan bereputasi (misal: Deepublish, Alfabeta, Kencana Prenada, dsb.).
3. **Pengajuan ISBN oleh Penerbit ke Perpusnas**:
   - Penerbit mengunggah naskah (cover, prelim, isi, dan RPS) ke sistem *ISBN Perpusnas* (`isbn.perpusnas.go.id`).
   - Nomor ISBN dan Barcode resmi terbit dari Perpustakaan Nasional RI.
4. **Deposit Karya Cetak & Rekam (KCKR)**:
   - Sesuai UU No. 13 Tahun 2018, kirimkan 2 eksemplar ke Perpustakaan Nasional RI dan 1 eksemplar ke Perpustakaan Daerah Jawa Timur.
